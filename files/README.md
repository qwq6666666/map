# 臺灣百年歷史地圖疊圖器

這是一個可以把日治時期、戰後不同年代的歷史地圖，疊在現在的地圖上比對的網站。可以搜尋地址、左右比對新舊地圖、拖曳時間軸依年代瀏覽、也可以在地圖上畫點線面做標註跟量測，並匯出成 GeoJSON 或圖片。

這份文件是寫給**不會寫程式**的你看的，說明「怎麼開起來看」「怎麼放到網路上」「以後想改東西該怎麼跟 Claude 說」。如果你是要接手改程式的開發者，請改看 [`DEVELOPMENT.md`](./DEVELOPMENT.md)。

## 這個網站是什麼

- 十幾種不同年代、不同地區的歷史地圖圖層（中央研究院、台北市政府等單位提供）
- 可以搜尋地址，網站會自動列出「這個地點目前有哪些年代的歷史地圖可以看」
- 四種瀏覽模式：透明疊圖、左右比對、時間軸（可以自動播放，像縮時影片一樣依序看歷史地圖演變）、複合疊圖（可以同時勾選多張歷史地圖一起疊在地圖上，各自調透明度、疊放順序）
- 可以在地圖上畫點、線、面做標註或量測距離／面積，並且匯出成檔案

## 資料夾裡有什麼

```
index.html       網站主頁面
style.css        網站的外觀樣式
src/             網站的程式邏輯（14 個檔案）
data/            所有歷史地圖的資料（哪個年代、哪個地區、圖磚網址等）
tools/           一支小工具程式，新增地圖資料後要跑一次
tests/           自動化測試，改完程式後可以跑一次確認沒有改壞
```

**平常你不需要打開這些檔案**，除非 Claude 請你把新版檔案覆蓋上去。

## 怎麼在自己電腦上打開看看

因為這個網站會用瀏覽器去讀取 `data/` 資料夾裡的檔案，**不能直接雙擊 `index.html` 打開**（瀏覽器會擋掉），需要一個很簡單的「本機伺服器」才能正常運作。

### 如果你電腦有安裝 Node.js

在資料夾裡新增一個檔案叫 `啟動網站.bat`，貼上這幾行：

```bat
@echo off
cd /d "%~dp0"
start http://localhost:3000
npx serve
```

之後**雙擊這個檔案**就會自動開瀏覽器、啟動網站。要關閉的話，把跳出來的黑色視窗直接關掉即可。

### 如果沒有裝過 Node.js

到 [nodejs.org](https://nodejs.org) 下載安裝（選 LTS 版本，一路下一步），裝好之後照上面的步驟做。

## 怎麼放到網路上讓大家都看得到

最簡單的方式是 **GitHub Pages**（免費）：

1. 到 [github.com](https://github.com) 註冊帳號、建立一個新的 repository（設為 Public）
2. 把 `index.html`、`style.css`、`src/` 資料夾、`data/` 資料夾整包上傳上去
3. 到 repository 的 Settings → Pages，Branch 選 `main`，資料夾選 `/ (root)`，儲存
4. 等 1～2 分鐘，會出現一個網址，例如 `https://你的帳號.github.io/專案名稱/`

之後要更新網站，只要把新的檔案上傳蓋過去就好，GitHub Pages 會自動更新（通常 1 分鐘內生效）。

## 以後想改東西，該怎麼跟 Claude 說

直接用平常聊天的方式描述你想要的效果或遇到的問題就可以，例如：

> 「搜尋出來的圖層太多了，可以只顯示前面幾筆嗎？」
> 「時間軸的箭頭可以再大一點嗎？」
> 「我截圖失敗了，畫面上什麼提示都沒有」

如果遇到問題，**打開瀏覽器的開發者工具**（按 `F12`，或右鍵選「檢查」），點選「Console」分頁，如果有紅字錯誤訊息，把那段文字複製貼給 Claude，會比單純說「壞掉了」更快找到問題。

## 新增一張歷史地圖的完整流程（進階，通常直接請 Claude 處理即可）

1. 在 `data/layers/` 底下新增一個來源檔案（格式可以參考同資料夾裡其他檔案）
2. 在 `data/layers/index.json` 裡加一筆
3. **執行 `node tools/build-layers-bundle.js`**（這一步一定要做，不然瀏覽器看到的還是舊資料）
4. 重新部署
